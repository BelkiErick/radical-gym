# Radical Gym — Producto

## Negocio y público

Gimnasio en Pifo, Quito, Ecuador. La landing está dirigida a personas que quieren conocer el club, consultar su membresía y ver las camisetas Radical Apparel. Idioma: español. Priorizar el uso desde celular.

## Estado actual

Web estática en HTML, CSS y JavaScript dentro de `dist/`. Vista previa mediante `node serve.mjs`. Sin backend, base de datos, autenticación ni procesamiento de pagos. Publicación futura pendiente; no desplegar como parte de una tarea de diseño.
